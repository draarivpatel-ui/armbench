ArmBench times real image and video kernels on this machine's Arm CPU, then sets the readings beside cloud figures that are always labeled as estimates. Nothing on this page presents a projection as a measurement.

Measured
Every timing comes from a live run of JavaScript kernels over seeded pixel buffers, timed with a monotonic clock in this page.
Estimated
Cloud figures are arithmetic projections of the local readings, built from published core clocks and a memory bandwidth heuristic. Each one carries an Estimate badge.
Not Used
No AWS Graviton instance was contacted. Local Apple Silicon stands in for Arm, and a documented path lets anyone rerun the identical suite on EC2.

Run the kernels on this machine. Pick a size and an iteration count, press Run, and every number in the results table comes from that live run.

One warmup pass runs uncounted before timing. A budget guard caps a timed pass at 12 million pixels, so a full run stays under about ten seconds.

    Why The Card Matters

    Reproducibility beats proximity. This project does not claim a machine the author did not run. It ships a portable benchmark suite, states exactly which machine produced the local numbers, and gives a documented plug in point for the target architecture.

    Reproduce On Graviton

    # Any AWS Graviton instance, Amazon Linux 2023, c7g family
# Node 18 or newer. No packages to install, no network calls.
node scripts/run-bench.mjs --seed 1337 --iterations 5 --json

# Same command, same table, on the cloud CPU.
# Paste the local results and the Graviton output side by side,
# and every honesty rule on this page still holds.
    04

    Report Export

    A copyable methodology block a judge can rerun. The report regenerates from the most recent completed run.

    Generate stays disabled until a run completes, because a report without a run would be fiction. The report includes the honesty statement, the estimate assumptions and the exact commands to reproduce.

    The text area is read only. Copy places the full report on the clipboard without altering it.
