    Audit And Verify

    Checksummed Export

    Sha-256 No export yet

    The digest is an unkeyed FIPS 180-4 SHA-256 tamper detection checksum computed by a pure JavaScript implementation in this page. It detects edits after export; it is not a signature and proves nothing about authorship. JSON is canonical with sorted keys, CSV escapes formula leading cells, and the export only contains sections backed by real runs.

    Bookmark Link

    The link encodes the seed, sizes, iterations, lab workload and lab size in a strict arm= hash token. Open the page with that hash and the same controls are restored. Anything malformed or out of range is rejected, never partially applied.

    Why The Card Matters

    Reproducibility beats proximity. This project does not claim a machine the author did not run. It ships a portable benchmark suite, states exactly which machine produced the local numbers, and gives a documented plug in point for the target architecture.

    Reproduce On Graviton

    # Any AWS Graviton instance, Amazon Linux 2023, c7g family
# Node 18 or newer. No packages to install, no network calls.
node scripts/run-bench.mjs --seed 1337 --iterations 5 --json

# Same command, same table, on the cloud CPU.
# Paste the local results and the Graviton output side by side,
# and every honesty rule on this page still holds.

    Report Export

    Generate stays disabled until a run completes, because a report without a run would be fiction. The report includes the honesty statement, the timing dispersion, the estimate assumptions and the exact commands to reproduce. Download saves the same text as a plain text file.

    The text area is read only. Copy places the full report on the clipboard without altering it.
